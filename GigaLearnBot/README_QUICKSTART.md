## Quickstart Guide for GigaLearnBot
Welcome to GigaLearnBot! This quickstart guide will help you get up and running with the bot in just a few simple steps.
###
1. Open x64 Native Tools Command Prompt for VS 2022.
2. Navigate to the GigaLearnBot directory:
   ```sh
   cd C:\Projects\RLGymBot_v3\GigaLearnBot\build
   ```
3. Compile the project using CMake:
   ```sh
   cmake --build .
   ```
4. Run the GigaLearnBot executable:
   ```sh
   GigaLearnBot.exe
   ```
5. The bot should now be training! You can monitor its progress through the console output.
